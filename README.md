# GameShelf for Windows

Download the latest `GameShelf-Setup.exe` from [Releases](https://github.com/chevezkevin/GameShelf-Releases/releases/latest) and run it to install or update GameShelf.

After installation, sign in with the Google account that was authorized for your license. GameShelf downloads and starts only games allowed by the active license in the private GameShelf system.

This repository publishes Windows installers only. GameShelf source code remains in the private repository.
